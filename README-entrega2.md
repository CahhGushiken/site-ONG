# Entrega 2 — CSS Avançado (SuperaCão)

## 🎯 Objetivo
Transformar a estrutura HTML da Entrega 1 em uma interface visual moderna e responsiva, aplicando técnicas de design system, layouts com Flexbox e Grid, e componentes interativos.

---

## 🧩 Especificações Técnicas Implementadas

### Sistema de Design
- Paleta de cores com 8 tons suaves e alegres (tema lúdico).
- Tipografia hierárquica usando *Poppins* e *Quicksand*.
- Sistema de espaçamento modular baseado em 8px.
- Variáveis CSS (`:root`) organizadas para fácil manutenção.

### Layouts Responsivos
- Uso de **Flexbox** e **Grid** para estrutura e alinhamento.
- Layout fluido com `auto-fit` e `minmax` (ajuste automático de colunas).
- Componentes centralizados e adaptáveis a qualquer tela.

### Navegação Interativa
- Menu principal com flexbox.
- Botões e links com estados visuais (hover, focus).
- Estrutura preparada para menu hambúrguer (JS opcional).

### Componentes de Interface
- **Cards responsivos** para os projetos.
- **Botões interativos** com hover e transições suaves.
- **Formulários estilizados** com feedback visual de validação.
- **Feedbacks visuais:** alerts, toasts e modais animados.
- **Badges e tags** para categorização.
